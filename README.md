# LangChain API Agent 🤖

Данный проект представляет собой минимального AI-агента на базе LangChain, который служит натурально-языковой обёрткой над API системы управления задачами.

## 🎯 Цель проекта
Реализовать агента, который может:
- Принимать запросы на естественном языке.
- Интерпретировать намерения пользователя.
- Вызывать методы API (Mock API) через инструменты (Tools).
- Возвращать структурированный ответ.

## 🛠 Технический стек
- **LLM:** Llama 3.2 1B (через Ollama)
- **Framework:** LangChain
- **Язык:** Python 3.12

## 🚀 Быстрый запуск
1. Установите [Ollama](https://ollama.com) и модель: `ollama run llama3.2:1b`
2. Создайте виртуальное окружение: `py -m venv venv`
3. Установите зависимости: `venv\Scripts\pip install -r requirements.txt`
4. Запустите агента: `venv\Scripts\python main.py "Ваш запрос"`

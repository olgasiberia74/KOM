# Project: Simple-Task-Manager 📋

## Что делает этот проект?
Это легкая библиотека на Python для создания, хранения и управления списком задач. Она позволяет пользователю добавлять задачи, отмечать их как выполненные и сохранять прогресс в JSON-файл.

## Основные сценарии использования
1. **Создание списка:** Пользователь инициализирует менеджер задач.
2. **Добавление задач:** Добавление новых пунктов с описанием и приоритетом.
3. **Управление статусом:** Перевод задачи из состояния "в процессе" в "завершено".
4. **Сохранение:** Автоматическая запись всех данных на диск для последующего использования.

## Как запустить проект
1. Клонируйте репозиторий: `git clone https://github.com/olgasiberia74/KOM.git`
2. Перейдите в папку: `cd KOM`
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите главный файл: `python main.py`

# Инструкции для AI-агента

При работе с данным проектом AI-агент обязан соблюдать следующие правила:

## 1. Формат подачи задач
- Каждый запрос должен содержать: **Цель**, **Контекст** и **Ожидаемый результат**.
- Если задача требует изменения архитектуры, агент обязан сначала предложить план изменений.

## 2. Технические ограничения
- **Стиль кода:** Строгое соблюдение PEP 8.
- **Типизация:** Все новые функции должны иметь Type Hints (аннотации типов).
- **Документация:** Любой новый метод должен сопровождаться Docstring в формате Google Style.
- **Обработка ошибок:** Использование специфичных исключений вместо общего `except Exception`.

## 3. Правила ответа
- Ответ должен содержать: 
    1. Описание внесенных изменений.
    2. Фрагмент кода "До" и "После".
    3. Инструкцию по проверке работоспособности.

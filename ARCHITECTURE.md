# Архитектура проекта

## Модули и ответственность
- `core/manager.py`: Основная бизнес-логика. Ответственность: управление списком задач, фильтрация, сортировка.
- `storage/json_handler.py`: Модуль работы с данными. Ответственность: чтение и запись JSON-файлов.
- `models/task.py`: Описание сущности "Задача". Ответственность: валидация данных задачи.
- `main.py`: Точка входа. Ответственность: взаимодействие с пользователем через консоль.

## Границы и ограничения
- **Запрещено:** Менять формат хранения данных (JSON) без согласования с архитектором.
- **Запрещено:** Добавлять внешние зависимости (библиотеки), которые увеличивают размер проекта более чем на 10МБ.
- **Ограничение:** Проект предназначен только для локального использования (без поддержки многопользовательского режима и БД).

# Лог промптов для разработки документации проекта

В данном документе зафиксированы все запросы к ИИ, которые использовались для создания структуры проекта, правил разработки и проверки работы AI-агента.

## 1. Создание базового описания и архитектуры
**Цель:** Сформулировать общую концепцию проекта, чтобы любой новый разработчик мог быстро войти в курс дела.

**Промпт:**
> "Действуй как ведущий разработчик. Мне нужно подготовить документацию для проекта 'Simple-Task-Manager' (менеджер задач на Python). 
> Создай два файла:
> 1. **README.md**: Напиши простое руководство для новичка. Укажи, что делает проект, основные функции и пошаговую инструкцию по запуску.
> 2. **ARCHITECTURE.md**: Опиши структуру проекта. Раздели его на модули (логика, хранение данных, модели, точка входа) и четко пропиши ответственность каждого модуля. Также укажи ограничения: что в проекте менять нельзя, чтобы не нарушить архитектуру."

---

## 2. Создание правил взаимодействия с ИИ (AI Guidelines)
**Цель:** Установить жесткие стандарты качества кода, чтобы ИИ-помощник выдавал готовый к работе код, который не нужно переписывать вручную.

**Промпт:**
> "Создай файл с правилами для ИИ-ассистента (`AI_GUIDELINES.md`), который будет работать с этим проектом. 
> Пропиши следующие обязательные требования:
> - **Качество кода:** Строгое соблюдение стандарта PEP 8.
> - **Типизация:** Обязательное использование аннотаций типов (Type Hinting) для всех функций.
> - **Документация:** Каждый новый метод должен иметь описание (Docstring) в стиле Google.
> - **Обработка ошибок:** Запрещено использовать общий `except Exception`, только конкретные ошибки.
> - **Формат ответа:** Ответ должен состоять из: описания изменений $\rightarrow$ сравнение кода 'До' и 'После' $\rightarrow$ инструкция по проверке."

---

## 3. Проверка инструкций на практике (Тест-драйв агента)
**Цель:** Убедиться, что ИИ действительно следует созданным правилам и не игнорирует ограничения.

**Промпт:**
> "Теперь представь, что ты — AI-агент, работающий в этом проекте. 
> **Задача:** Добавь в модель задачи поле 'Приоритет' (Low, Medium, High).
> **Важное условие:** Ты обязан строго следовать инструкциям из файла `AI_GUIDELINES.md`. Если ты забудешь добавить типы данных или Docstring, задача будет считаться невыполненной. 
> Выдай ответ строго в формате: Описание $\rightarrow$ Код До/После $\rightarrow$ Проверка."

---

## 4. Финальная сборка всех файлов
**Цель:** Объединить все наработки в итоговый набор файлов для репозитория.

**Промпт:**
> "Собери все созданные документы (README, Архитектуру, Правила ИИ и Примеры задач) в финальные Markdown-файлы. Проверь, чтобы тексты были согласованы между собой и выглядели как единый профессиональный проект. Выведи содержимое каждого файла отдельно."

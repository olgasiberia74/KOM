# Использованные промпты

1. Задача: создать простое приложение "Мини-анкета" с backend и frontend.
   - Backend: Python + FastAPI
   - API: `GET /questions`, `POST /answers`
   - Frontend: HTML + JS
   - Фронтенд загружает вопросы, отправляет ответы и показывает сообщение "Спасибо!"

2. Запрос на добавление маршрутов и файлов интерфейса.

3. Запрос на сохранение всех промптов, использованных в процессе.

4. Запрос: "сделай---Если установить зависимости из requirements.txt, тесты будут работать"
   - Установка зависимостей: pip install -r requirements.txt
   - Дополнительно: pip install httpx pydantic-settings
   - Исправление импорта BaseSettings
   - Добавление __init__.py в app/
   - Исправление пути к static/
   - Запуск сервера с PYTHONPATH
   - Тестирование API через PowerShell
